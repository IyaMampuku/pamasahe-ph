# Pamasahe PH

A mobile-first public transit guide for Metro Manila. Help users find jeepney and bus routes, estimated fares, and travel times with ease.

## Features
- **Bilingual Support**: Switch between English and Tagalog.
- **Interactive Map**: Real-time geolocation and route plotting using Leaflet.
- **Trip Guide**: Step-by-step navigation with a custom bottom sheet.
- **PWA**: Installable on mobile devices for quick access.

## Tech Stack
- **Frontend**: React (Vite + TypeScript)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Mapping**: React Leaflet
- **Animations**: Framer Motion
